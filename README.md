# SCNU COMA

SCNU COMA는 React와 HTML5 Canvas를 이용해 제작된 박진감 넘치는 플래피 버드 스타일의 웹 게임이야.

## 게임 소개
- **캐릭터 선택**: '코미'와 '콤마' 중 원하는 캐릭터를 선택해 플레이할 수 있어.
- **레벨 시스템**: 점수가 올라갈수록 레벨이 상승하며 게임 속도가 빨라져 긴장감을 더해줘.
- **피버 타임**: 특정 점수에 도달하면 12초 동안 무적 상태가 되고 초고속 부스터가 발동되는 피버 타임을 즐길 수 있어.
- **생명 시스템**: 총 3개의 하트가 주어지며, 장애물에 부딪혀도 다시 기회를 얻을 수 있어.

## 기술 스택
- **Framework**: React 18
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: TailwindCSS v4
- **Graphics**: HTML5 Canvas API
